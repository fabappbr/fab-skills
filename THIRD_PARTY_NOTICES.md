# Avisos de terceiros

O texto das skills deste repositório é da Fabapp AI e está sob a licença MIT (arquivo `LICENSE`). As skills foram
escritas a partir de técnicas de skills de código aberto, listadas abaixo com a licença de cada uma. Nenhum arquivo
dessas fontes foi copiado como está; onde uma skill se baseia de perto numa fonte, o `README.md` da skill traz a
origem, a licença e o aviso de copyright correspondentes, como as licenças MIT e Apache 2.0 pedem.

Para as fontes em Apache 2.0: as skills daqui são obras derivadas modificadas (reescritas em português e adaptadas à
Fabapp AI); o texto da licença Apache 2.0 está em https://www.apache.org/licenses/LICENSE-2.0. O projeto
`pbakaus/impeccable` tem um `NOTICE.md` próprio sobre material de terceiros, reproduzido por referência no README
das skills que o usam.
